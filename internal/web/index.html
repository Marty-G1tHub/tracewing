VPS 测速

你的 VPS 线路和机器本身怎么样？测四组吞吐、时延，并给出带证据的诊断。

来源
公共端点测的是“本机到公共测速源”，不是你的 VPS，只用来对照参考。
档位
高级UDP 目标速率 · 本地上行上限

四组吞吐：上行 / 下行 × 单流 / 4 流，加应用层 echo 时延与 TCP 握手；自带服务端还会回传 CPU / 内存。服务端部署：./tracewing --server --port 9527，令牌启动时会打印，详见 README。

线路检测

去程与回程走的是哪条线路？本机逐跳探测到你的服务器；服务器上的 agent 再逐跳探测回国内三网四地，并给出带证据的判定（CN2 GIA / GT、AS9929、CMIN2 等）。

回程需要在服务器上部署 agent（一条命令，见 README）；agent 只能探测固定的 12 个国内目标和你的出口 IP，不会执行任何命令。

历史记录

每次测速都会保存为一份离线报告，随时回看或对比。
